1. INSTALLATION DANS XAMPP (htdocs)
------------------------------------------------------------
1) Extrayez tout le contenu du fichier ZIP dans :
     C:\xampp\htdocs\iset_notes\
   (Alternative WAMP : C:\wamp64\www\iset_notes\)

2) Ouvrez "XAMPP Control Panel" et démarrez :
   - Apache
   - MySQL

Logo ISET Djerba :
- Le logo vectoriel officiel est déjà inclus dans img/logo.svg.
- Si vous préférez utiliser votre propre image PNG, copiez-la
  simplement en tant que img/logo.png (détection automatique).

2. BASE DE DONNÉES MYSQL (phpMyAdmin)
------------------------------------------------------------
Configuration déjà prête dans connect.inc.php :
  Hôte : localhost | Base : notes | Utilisateur : root | Mot de passe : (vide)

- NOUVELLE INSTALLATION (recommandé) :
  1) Ouvrez http://localhost/phpmyadmin
  2) Cliquez sur l'onglet "Importer"
  3) Sélectionnez notes.sql puis cliquez sur "Importer"

- BASE "notes" DÉJÀ EXISTANTE :
  Importez uniquement notes_roles.sql dans votre base "notes".
